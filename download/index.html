Pick the package for your platform. Every release is built automatically and published on GitHub.

How do I know which one to choose?
  • Windows: open Settings, then System, then About, and read "System type". "64-bit, x64-based" means x86_64. "ARM-based" means ARM64.
  • Linux: run uname -m. x86_64 means x86_64, aarch64 means ARM64, i686 means x86, armv7l means ARM.
  • macOS, Android and iOS: there is only one package for each, so there is nothing to choose.
  • Not sure? On almost every Windows or Linux computer sold in the last ten years, x86_64 is the right one.
