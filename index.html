Why Rebax

A different export model: your project is compiled, not interpreted.

Truly native output

Exports are compiled programs. Only the code and resources you use are included, so builds stay small and start fast.

One project, many targets

Write once and export to Windows, Linux, macOS, Android and iOS from the same project.

Classic consoles

PlayStation 2 and PlayStation 1 are first-class project types with their own SDKs and exporters.

Nodes today, more to come

Start with a visual node workflow. A low-level development system for apps and games is planned.

Install only what you need

Target packages are downloaded on demand and cached. Nothing you do not use sits on your disk.

Open and buildable anywhere

Build the engine from source on any supported host with a single command. Contributions are welcome.

How it works

From an empty project to a native program in three steps.

Create a project

Choose a project type: the modern platforms, PlayStation 2 or PlayStation 1. Build your scenes with nodes in the editor.

Install the target you need

Open the package window and install the SDK and compiler for your target. Packages are downloaded once and reused.

Export

Rebax generates the code, compiles it and gives you the finished program. Run it, share it, or send it to a real console.
