Rebax Engine

A cross-platform engine for creating applications and games. Build your project once and export it as a native program for desktop, mobile and console platforms.

Download Documentation

Features

Everything you need to take a project from an idea to a finished program.

Native performance

Exported projects are real programs for each platform, small in size and quick to start.

One project, many platforms

Create a project once and export it to every supported platform from the same editor.

Console support

PlayStation 2 and PlayStation 1 are supported as project types, with export built in.

Visual workflow

Build scenes and logic with nodes in an integrated editor.

Install what you use

Components for each platform are downloaded on demand, so your installation stays small.

Open source

The engine is developed in the open and can be built from source. Contributions are welcome.

Export your project to any of the following.

How it works

From a new project to a finished program.

Create a project

Start a new project and choose the type that matches where you want it to run.

Build it in the editor

Create scenes, add assets and set up behavior with the visual node workflow.

Export

Choose a platform and export. Rebax prepares everything and gives you the finished program.
