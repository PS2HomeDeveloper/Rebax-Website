Installation

Download the package for your platform from the download page. Extract it and run Rebax. No installer is required.

Projects

A project is a folder that holds your scenes and assets. When you create one, you choose its type:

  • Modern platforms for Windows, Linux, macOS, Android and iOS.
  • PlayStation 2 for the PlayStation 2 console.
  • PlayStation 1 for the PlayStation 1 console.

Projects are currently built with the visual node workflow in the editor.

Exporting

Open the export window, choose the platform you want and start the export. Rebax produces a finished program that is ready to run or share.

The first time you export to a platform, Rebax downloads the components that platform needs. They are stored on your computer and reused for later exports.

Exporting for macOS and iOS requires a Mac.

Building from source

You need Git and make. Everything else is downloaded automatically.

git clone https://github.com/PS2HomeDeveloper/Rebax.git
cd Rebax
make

This builds Rebax for the computer you are using. To build for another platform, name the platform and architecture:

make windows x86_64
make linux arm64

Repositories

  • Rebax: the engine and editor.
  • Rebax SDKs: components used to export to each platform.
  • Rebax Toolchains: compilers used by the export process.
  • Rebax Website: this website.
