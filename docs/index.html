Getting started

  1. Download the package for your platform from the download page.
  2. Extract it and run Rebax. On Android, install the APK.
  3. Create a project, then open the package window and install the target you want to export to.

Packages (SDKs and compilers) are downloaded the first time you need them and reused afterwards.

Projects

A project is one folder with a project.rebax file and an assets folder. Rebax has three project types:

  • Modern platforms: one project for Windows, Linux, macOS, Android and iOS.
  • PlayStation 2: built for the console’s limits and tooling.
  • PlayStation 1: the same idea for the original console.

Today projects are built with the node workflow. A low-level development system for writing apps and games directly against the Rebax native API is planned.

Targets and packages

Exports are compiled with the compiler package (clang, or gcc for the PlayStation targets) against the SDK package of the target. Both are installed from the package window. The engine uses a compiler already on your machine when it can.

iOS and macOS exports can only be produced on a Mac, because they need Apple’s tools.

Build from source

You only need Git and make. The build downloads what it needs.

git clone https://github.com/PS2HomeDeveloper/Rebax.git
cd Rebax
make

That builds the engine for the machine you are on. To build for another platform:

make windows x86_64
make linux arm64
make android all
make android arm64-v8a

make android all produces a single APK containing every Android architecture.

Repositories

  • Rebax — the engine and editor.
  • Rebax SDKs — the target SDK packages.
  • Rebax Toolchains — the compiler packages.
  • Rebax Website — this website.

PlayStation 2 run over the network

With a PlayStation 2 project open, the run menu can send your game to a real console through ps2link. The PlayStation 2 needs a network connection (a built-in port on slim models, the network adapter on the original model) and ps2link.elf running. The in-engine setup window walks you through it and exports the two files you need.
